# LIFEMAXING frontend product context

Source: user's approved 15 September 2026 redesign brief and docs/PROJECT_SPEC.md. This context records existing product truth; no new product assumptions.

## Platform
Responsive web application for desktop, tablet and mobile. Private authenticated personal workspace.

## Purpose
A personal operating system joining daily planning, execution, habits, goals, life areas, progress and an honest history. The owner uses it repeatedly over years; it must combine a personal emotional entrance with precise daily controls.

## Working capabilities
Today, Tasks/Inbox, Goals, Habits, ten Life Areas, Progress/Activity/Rewards, server-persisted Focus, Settings, session security. Existing APIs and owner isolation are authoritative. No public registration or invented data.

## Stack
React JavaScript/JSX, React Router, TanStack Query, React Hook Form/Zod, CSS Modules; ASP.NET Core/C# and PostgreSQL. No TypeScript or new UI framework.

## Commitments
Preserve exact approved Joint geometry and original PNG assets. All four existing UI languages, account time zone, theme/density, keyboard semantics and reduced motion remain supported. Do not invent calendar, AI, finances module, ranks or history fields.
