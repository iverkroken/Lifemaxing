# World Clock geography

The bundled `worldMapData.json` is generated by `node scripts/generate-world-clock-map.mjs`.
It uses an equirectangular projection, shared by the land outline and city markers.

- Natural Earth 1:110m land, source commit `ca96624a56bd078437bca8184e78163e5039ad19`:
  https://github.com/nvkelso/natural-earth-vector/blob/ca96624a56bd078437bca8184e78163e5039ad19/geojson/ne_110m_land.geojson
  Public domain: https://www.naturalearthdata.com/about/terms-of-use/
- IANA tzdb 2026d, `zone1970.tab`, `zone.tab` and Link aliases:
  https://data.iana.org/time-zones/releases/tzdata2026d.tar.gz
  These geographic tables and timezone data are public domain. `zone.tab` supplies
  country-specific exemplar locations even when clocks share post-1970 rules.

This metadata supplies approximate representative locations, never UTC offsets.
Clock calculations continue to use the browser's current Intl timezone database.
Non-geographic zones have no pin. Named major-city aliases use explicit coordinates
in `worldLocations.js`; a local timezone pin represents its exemplar city, not GPS.
No account data is sent to a map provider. No network map requests run in the app.
